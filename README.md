# Template

plugin template for [fwmod-core](https://github.com/fnafworldmodding/fwmod-core)

## how to install?
copy the zip (either by download as source or releases (recommended)) 
to `C:\Users\[User name]\Documents\Visual Studio 2022\Templates\ProjectTemplates` than you should see it by searching plugin or fwmod

> [!NOTE]  
> make sure that visual studio version match, 2022 is being used as an example here
